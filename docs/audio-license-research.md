# External audio licensing research

## Mixkit

- License page: https://mixkit.co/license/
- Sound-effects collection: https://mixkit.co/free-sound-effects/
- Siren collection: https://mixkit.co/free-sound-effects/siren/
- The Mixkit collection states that sound effects are available under the Mixkit License. The Mixkit sound-effects page states that its free sound-effects license permits use in commercial and personal projects. The license page distinguishes sound effects from other item types, so this record applies only to the downloaded sound-effect files.
- Individual item pages/download endpoints and exact asset URLs will be recorded in `audio-sources.md` after download, together with SHA-256 hashes.

## Wikimedia Commons / public domain reference

- Example verified public-domain police siren page: https://commons.wikimedia.org/wiki/File:American_police_siren_i.ogg
- The page identifies the author as `lezer`, states that the source is PDSounds, and explicitly says the recording was released into the public domain for any purpose. This source is suitable for commercial use, subject to retaining provenance documentation.
- This project will not use a file unless the item page contains an explicit license or public-domain statement that covers redistribution in an Android application.

## Pixabay caution

- License summary: https://pixabay.com/service/license-summary/
- Pixabay permits free use, modification, and commercial use subject to its restrictions, but warns that additional intellectual-property rights may apply and prohibits standalone redistribution. For that reason, Pixabay files will not be used unless the specific item and intended embedded-app use are separately verified.

## Policy for this project

No file described only as “royalty-free” or “no copyright” will be accepted. Every shipped sound must have an item-level source URL, an explicit commercial-use basis, download URL, author/creator when available, retrieval date, and SHA-256 hash recorded in `audio-sources.md`.
